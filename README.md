# Виживші: Мутація 2050

Браузерна постапокаліптична гра про виживання в світі 2050 року. Проєкт — статичний веб-сайт без збірки: HTML-сторінки, CSS і логіка на чистому JavaScript.

## Сюжет

Після глобальної катастрофи світ заповнили мутовані істоти та руїни колишніх міст. Виживання залежить від пошуку їжі, води та ресурсів, поліпшення бази й боїв із небезпечними мутантами. Мутації тварин — наслідок корпоративних експериментів, що тривали до краху цивілізації.

Детальніше про світ гри — на сторінці [about-the-game.html](about-the-game.html).

## Ігровий процес

- **Ресурси:** жетони, кристали, енергія, вода, металобрухт, їжа (сире та смажене куряче м’ясо), дизельне паливо, світлошумові гранати.
- **Пасивний дохід:** щогодини нараховуються жетони, кристали та вода (якщо вистачає енергії); відновлюється здоров’я та ліміт боїв.
- **Покращення:** кваліфікація (швидкість заробітку жетонів), кристальна ферма, збірник води.
- **Локації:**
  - [index.html](index.html) — головна, склад, покращення
  - [house.html](house.html) — дім (кухня, майстерня)
  - [kitchen.html](kitchen.html) — приготування їжі
  - [workshop.html](workshop.html) — крафт
  - [shop.html](shop.html) — магазин
  - [converter.html](converter.html) — обмін ресурсів
  - [safe-zone.html](safe-zone.html) — безпечна зона
  - [before-hunting.html](before-hunting.html) → [hunter.html](hunter.html) — покинуті землі, полювання на мутантів
- **Бій:** атака та гранати проти ворогів; перемога дає здобич, поразка карає втратою жетонів.

Прогрес зберігається в `localStorage` (ключ `gameTutorial`) автоматично кожну секунду.

## Структура проєкту

| Файл / каталог | Призначення |
|----------------|-------------|
| `scrypt.js` | Ігрова логіка, UI, збереження |
| `main.css`, `alternative-main.css` | Стилі |
| `media/` | Зображення, іконки, спрайти тварин |
| `*.html` | Сторінки локацій |

## Запуск

Достатньо відкрити [index.html](index.html) у браузері або підняти локальний HTTP-сервер:

```bash
python -m http.server 8000
```

Потім перейти на `http://localhost:8000`.
